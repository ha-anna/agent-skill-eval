# Summarize

## Instructions

1. Identify the source the user wants summarized. If it is missing or inaccessible, ask the user to provide it.
2. Capture the main points and any caveats needed to preserve their meaning. Use only information supported by the source.
3. Follow the user's requested length and format. If none is specified, give a short overview followed by the key takeaways.
